🎲 Tilt & Tip-Over Board Game

Authors: Jet Li and Benson Zhou

This project is a Java-based redesign of the classic Tilt and Tip-Over board games. It offers both GUI and PTUI (Plain Text User Interface) formats, allowing players to enjoy the game in multiple ways.

🌟 Features
Graphical User Interface (GUI): Play with an interactive, visual board.
Plain Text Interface (PTUI): Play directly in the console for simplicity.
Hint System: Get suggestions for your next move.
Backtrack Functionality: Undo moves to explore different strategies.

🛠️ Technologies Used
Java 
Java FX
